h

hm2b bundle 检查器

上传 → 校验 → 编译产物预览 → 投影 → 构建。只读操作，不写入项目；浏览器不接触 GitHub token。

启动中 降级模式 发布未启用
浏览器不支持

请使用 Chrome/Edge 123+、Firefox 127+ 或 Safari 17.5+，或改用 CLI：

node bin/hm2b-assembler.js bundle validate ./bundle.zip --json
node bin/hm2b-assembler.js compile ./bundle.zip --out ./dist

然后重新运行 npm run web。这里不做 user-agent 嗅探；只有缺少必需能力时才会显示。
