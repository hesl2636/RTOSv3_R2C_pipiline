hm2b bundle inspector

Local surface: read-only bundle and IR, editable projection options, local build, server-side publish. Nothing is installed or written to a project, and the browser never sees the GitHub token.

Unsupported browser

Open this page in Chrome/Edge 123+, Firefox 127+ or Safari 17.5+, or use the CLI:

node bin/hm2b-assembler.js bundle validate ./bundle.zip --json
node bin/hm2b-assembler.js compile ./bundle.zip --out ./dist

Then serve the repository again with npm run web. No user-agent sniffing is used; this page is shown only when a required primitive is missing.

                    6. Publish release
                    
      
                    Publishing runs on the server only: it calls the release tool as a child process, keeps the GitHub token in server memory, and never sends the token (or talks to GitHub) from this page. A published release is never rewritten — a bad version gets a new patch.
